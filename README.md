# ClearAnEstate.com

Directory of estate cleanout, senior move management, junk removal, and estate sale liquidation professionals, connecting probate executors, attorneys, and families with insured local providers.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env` and fill in the values you need (see comments in that file). Everything is optional for local development — without a database configured, the app falls back to local seed data and browser storage.
3. Run the app:
   `npm run dev`

See [PRODUCTION_ROADMAP.md](PRODUCTION_ROADMAP.md) for what's needed to take this from local dev to a live production deployment on Namecheap.
